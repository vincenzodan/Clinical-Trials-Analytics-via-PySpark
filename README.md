# 🏥 Clinical Trials Analytics via PySpark

Questo progetto ha come obiettivo l'analisi di un dataset di **clinical trials** utilizzando **Apache Spark** (PySpark).  
I **clinical trials** (studi clinici) sono studi scientifici condotti su soggetti umani per valutare la sicurezza e l’efficacia di trattamenti medici, farmaci o procedure. Il dataset utilizzato proviene da **Dimensions.ai**, una piattaforma che aggrega dati su ricerca scientifica a livello globale.  
Ogni riga del dataset rappresenta uno **studio clinico**, con colonne che includono metadati, condizioni mediche, organizzazioni coinvolte e localizzazioni geografiche.
